# GỐM BÁCH NGÂN HỶ — WEBSITE DEMO (HTML/CSS/JAVASCRIPT)

## Chạy nhanh
1. Giải nén ZIP.
2. Mở file `index.html` bằng trình duyệt Chrome/Edge.
3. Điều hướng trang chủ, Shop, Quà tặng, Chi tiết, Giỏ hàng, Checkout mô phỏng.

## Đăng GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload **toàn bộ nội dung bên trong thư mục sau khi giải nén**, đặc biệt là `index.html` ở cấp cao nhất (root).
3. Vào Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
4. Truy cập đường dẫn GitHub Pages được GitHub cung cấp.

## Ghi chú
- Đây là bản demo phục vụ đồ án, **không phải cửa hàng chính thức**.
- Giá bán trong phần sản phẩm demo không phải báo giá được shop xác nhận.
- Giỏ và đơn mô phỏng chỉ lưu cục bộ trong trình duyệt (`localStorage`). Không có backend, cổng thanh toán hoặc giao hàng thật.
- Ảnh gốm lấy từ các ảnh do người dùng cung cấp.
- Không được tuyên bố website nhận đơn thật hoặc thuộc quyền sở hữu chính thức của shop.
